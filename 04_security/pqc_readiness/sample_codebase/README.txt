SYNTHETIC SAMPLE CODEBASE -- NOT REAL CODE, NOT A REAL COMPANY
===============================================================
Every file in this folder was written by hand for the PQC readiness demo. It belongs to a
fictional organization ("SampleCo Finance") and exists only so the crypto inventory
scanner has something realistic to find. It contains no real keys, hosts, credentials or
company data. Hostnames use the reserved example.com / example.internal names.

The mix is deliberate: some files use quantum-vulnerable public-key crypto, some use
classically weak algorithms that should already be gone, one file is already migrated
to post-quantum cryptography, and one file is clean but full of near-miss words that a
careless scanner would flag.
